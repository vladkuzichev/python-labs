# Окремий автономний комплект

Ця сторінка пояснює комплект `READY_TO_SUBMIT.zip`. Сам ZIP не розміщено в цьому репозиторії.
У звичайному GitHub-клоні немає Runtime, Offline/wheelhouse, Reports або Tests;
для нього використовується [основний README](../README.md).

Після розпакування окремого ZIP у Windows x64 слід відкрити папку `READY_TO_SUBMIT` і запустити
`INSTALL_OFFLINE.cmd`, потім `RUN_FINDEX.cmd` або `RUN_TESTS.cmd`.
Там же є справжній файл `INSTALL_OFFLINE.md` з подробицями; це не посилання на відсутній файл клону.
Переносимий CPython 3.13.18 і wheelhouse входять у комплект. Наявний `.venv` не переноситься,
оскільки він може містити абсолютний шлях до локального інтерпретатора.

Розміщення окремих матеріалів відносно папки комплекту:

| Матеріал | Шлях у комплекті |
|---|---|
| Код із Git-історією | `Project/` (у локальному робочому комплекті); у ZIP історія також є як bundle |
| Історія для відновлення | `Documentation/findex.bundle` |
| Звіти для окремої здачі | `Reports/Lab_01.docx` … `Reports/Lab_08.docx` |
| Повні журнали початкових дослідів | `Tests/` |
| Оригінальні методички та notes | `Documentation/SourceMaterials/` |
| Початкові скриншоти та sample | `Documentation/SourceMaterials/` |
| Корпус, індекс, ембеддинги | `Project/data/` |
| Локальна модель | `Project/models/` |

Після аудиту звіти оновлено в локальному `READY_TO_SUBMIT/Reports/`; попередній ZIP відображає
стан до аудиту. Актуальні файли і контрольні суми додаткового пакета наведено в
[SUBMISSION](SUBMISSION.md). Інструменти, дані та особисті реквізити зі звітів не публікуються в Git.
Навчальні відповіді та поточний сценарій захисту доступні в [DEFENSE](DEFENSE.md) цього репозиторію.
