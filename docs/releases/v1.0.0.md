# findex v1.0.0 — векторне та семантичне ранжування

Код відповідає версії v1.0.0; документацію відредаговано в гілці `text-review/lab-08`.
Містить CLI, async crawler, FastAPI/Jinja, int32/NumPy BM25 і TF-IDF,
MiniLM/ONNX, cosine, best-chunk-per-doc та RRF. У snapshot: 103 тести;
перевірений GitHub Actions №43021534036 завершився успішно.

Assets: `findex-1.0.0-py3-none-any.whl`, `findex-1.0.0.tar.gz`, `SHA256SUMS.txt`.
[Контрольні суми та звірка source](../evidence/release-v1.0.0-manifest.json).
Тексти, модель і ембеддинги потрібно створити/завантажити окремо.

Код пакета відповідає історичній версії; текст документації оновлено без зміни реалізації. Виправлення README, Dockerfile,
шляхів журналів і неблокуючої ініціалізації crawler у наступному main до цього
незмінного пакета не підмішуються. Публічне розгортання не виконано;
P@5 ґрунтується на неповній розмітці релевантності. Додатковий Release №8 прямо не вимагається.

Статус: локальний пакет, ще не опублікований GitHub Release.
