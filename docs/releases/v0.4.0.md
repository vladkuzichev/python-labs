# findex v0.4.0 — типізований CLI

Матеріал до обов'язкового GitHub Release лабораторної №4. Код відповідає версії v0.4.0; документацію відредаговано в гілці `text-review/lab-04`.

Pyright/Mypy strict, logging/stderr, JSONL/stdout, fixtures, 58 pytest-тестів
і щонайменше три Hypothesis-властивості. Збережено src-layout та uv.lock.

Підготовлені assets: `findex-0.4.0-py3-none-any.whl`, `findex-0.4.0.tar.gz`, `SHA256SUMS.txt`.

або окремий сумісний wheelhouse.

Історичний тег містить workflow, але окремий CI-run на цьому тегу не стверджується.
